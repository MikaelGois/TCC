# 📚 Trabalho de Conclusão de Curso (TCC)

Este repositório reúne os materiais do Trabalho de Conclusão de Curso de **Mikael Gois**, desenvolvido no **Instituto Federal de Educação, Ciência e Tecnologia de Sergipe (IFS) - Campus Itabaiana**.

---

## 🎯 Objetivo
O projeto tem como foco a **revisão sistemática** relacionada ao tema do TCC, organizada e documentada em formato de notebook Jupyter.

---

## 🗂 Estrutura Atual
- `Revisão_sistemática.ipynb` → Notebook principal contendo:
  - Metodologia da revisão sistemática
  - Coleta e organização das referências
  - Análises iniciais

---

## ⚙️ Tecnologias Utilizadas
- **Python**
- **Jupyter Notebook**
- Bibliotecas: `pandas`, `numpy`, `matplotlib` (e outras conforme evolução do trabalho)
